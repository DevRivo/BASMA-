# BASMA API v1

Base path: `/api/v1` · JSON response envelope: `{ "success": true, "data": ..., "meta": ... }`. Errors: `{ "success": false, "error": { "code": "...", "message": "...", "details": [...] } }`.

Authentication is required where marked **Auth**. Browser requests should use `credentials: 'include'`. Bearer access tokens are also accepted. IDs are opaque strings generated by Prisma.

## Auth

| Method | Path | Auth | Body / purpose |
|---|---|---:|---|
| POST | `/auth/register` | No | `{email, username, password, bio?}`. Creates account and session. |
| POST | `/auth/login` | No | `{email, password}`. |
| POST | `/auth/refresh` | Refresh cookie or body | Rotates refresh token. |
| POST | `/auth/logout` | Optional | Revokes refresh token and clears cookies. |
| GET | `/auth/me` | Yes | Current user. |
| PATCH | `/auth/password` | Yes | `{currentPassword, newPassword}`. Revokes sessions. |
| POST | `/auth/forgot-password` | No | `{email}`. Generic response; delivery provider must be configured. |
| POST | `/auth/reset-password` | No | `{token, newPassword}`. Single-use token. |
| POST | `/auth/resend-verification` | Yes | Creates verification token; configure mail delivery. |
| POST | `/auth/verify-email` | No | `{token}`. |
| GET | `/auth/oauth/google` or `/auth/oauth/facebook` | No | Explicit 501 until OAuth credentials/callback are configured. |

## Users and categories

| Method | Path | Auth | Purpose |
|---|---|---:|---|

| GET | `/users/:id` | No | Public profile, artwork preview and statistics. |

## Private and group chat

| Method | Path | Auth | Purpose |
|---|---|---:|---|
| POST | `/conversations` | Yes | `{userId}`; creates or returns direct conversation. |
| GET | `/conversations` | Yes | Current user's conversations, last message and unread count. |
| GET | `/conversations/:id/messages?page=&limit=` | Participant | Read messages and update that participant's last-read cursor. |
| POST | `/conversations/:id/messages` | Participant | `{type:"TEXT", content}` or `{type:"IMAGE", imageUrl}`. |
| POST | `/conversations/:id/read` | Participant | Update read cursor and emit read event. |
| GET | `/communities/:id/messages` | Accepted member | Group messages; updates community-specific last-read cursor. |
| GET | `/communities/:id/unread` | Accepted member | `{unreadCount}`. |
| POST | `/communities/:id/messages` | Accepted member | `{type:"TEXT", content}` or `{type:"IMAGE", imageUrl}`. |

Messages do not support audio/video/calls. Conversation unread state is independent from notification read state. Community unread count is calculated per member using the community membership read cursor.

## Notifications and uploads

| Method | Path | Auth | Purpose |
|---|---|---:|---|
| GET | `/notifications?page=&limit=` | Yes | List, unread count and actor. |
| PATCH | `/notifications/:id/read` | Owner | Mark one notification read. |
| POST | `/notifications/read-all` | Yes | Mark all own notifications read. |
| DELETE | `/notifications/:id` | Owner | Delete own deletable notification; system announcements are protected. |
| POST | `/notifications/announcements` | Admin API key | `{title, body?}` plus `x-admin-key`; creates protected system announcements. |
| POST | `/uploads/image` | Yes | Multipart `image`, optional `folder`; returns Cloudinary URL/publicId. |

Notification types: `PRIVATE_MESSAGE`, `COMMUNITY_MESSAGE`, `FRIEND_REQUEST`, `FRIEND_REQUEST_ACCEPTED`, `COMMUNITY_JOIN_REQUEST`, `COMMUNITY_JOIN_ACCEPTED`, `COMMUNITY_JOIN_REJECTED`, `ARTWORK_LIKE`, `ARTWORK_COMMENT`, `SYSTEM_ANNOUNCEMENT`.

## Socket.IO events

Authenticated connection required. Client may pass `auth: { token }` or use cookies.

- Client → server: `conversation:join` `{conversationId}`, `community:join` `{communityId}`, `room:leave` `{room}`.
- Server → client: `message:new`, `notification:new`, `conversation:read`.
- Joining a room requires verified database membership. Do not send messages through arbitrary client socket payloads; post to REST so persistence and authorization happen first.

## Common status codes

- `400` invalid body/query or business rule.
- `401` missing/expired/invalid authentication.
- `403` authenticated but unauthorized.
- `404` resource not found or not visible to caller.
- `409` duplicate relationship/resource.
- `413` uploaded file too large.
- `415` unsupported image MIME type.
- `429` rate limit exceeded.
- `501` OAuth provider not configured.
- `503` Cloudinary not configured.
