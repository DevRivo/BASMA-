# BASMA – بصمة

واجهة أمامية عربية RTL مبنية باستخدام HTML5 وCSS3 وVanilla JavaScript فقط.

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `BASMA` في محرر الأكواد.
3. شغّل خادمًا محليًا من جذر المجلد (مثل Live Server في VS Code).
4. افتح `index.html`.

> لا تفتح الصفحات مباشرة عبر `file://` لأن تحميل ملف التصنيفات JSON يستخدم `fetch` ويحتاج خادمًا محليًا.

## الصفحات
- `index.html`: الرئيسية والأسئلة الشائعة.
- `pages/artwork.html`: معرض الأعمال والبحث والتصنيف والإعجاب والتعليقات والنشر.
- `pages/artists.html`: اكتشاف الفنانين وطلبات الصداقة والمحادثات التجريبية.
- `pages/communities.html`: المجتمعات وطلبات الانضمام وإنشاء مجتمع.
- `pages/notifications.html`: واجهة الإشعارات.
- `pages/account.html`: نقطة الدخول للحساب والملف الشخصي.

## البيانات والتخزين
تُحفظ بيانات العرض التجريبي في `localStorage` تحت المفتاح `basma_db`. لا تُخزن كلمات المرور. تسجيل الدخول وإنشاء الحساب محاكاة محلية فقط.

## حدود النسخة الحالية
هذه نسخة Frontend Demo وليست منصة إنتاجية. لا يوجد backend أو إرسال حقيقي بين مستخدمين أو OAuth أو بريد إلكتروني أو تخزين سحابي. بعض تدفقات الموافقة والإشعارات المتقدمة تحتاج خادمًا وقاعدة بيانات وصلاحيات حقيقية. الصور التجريبية تُحمّل من Unsplash وتتطلب اتصالًا بالإنترنت.
