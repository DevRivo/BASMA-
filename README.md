# بصمة BASMA — الواجهة الأمامية

منصة مجتمع فني عربية RTL مبنية باستخدام HTML5 وCSS3 وVanilla JavaScript وSVG فقط، بدون React أو Vue أو Bootstrap أو Tailwind.

## التشغيل محليًا

1. فك ضغط `BASMA.zip`.
2. افتح مجلد المشروع في الطرفية.
3. شغّل:

```bash
python3 -m http.server 8000
```

4. افتح `http://localhost:8000` في المتصفح.

يفضّل استخدام خادم محلي بدل فتح الملفات مباشرة، خصوصًا عند استخدام وحدات المتصفح ورفع الصور.

## حساب تجريبي

- البريد: `demo@basma.art`
- كلمة المرور: `123456`

## الصفحات

- `index.html` — الرئيسية والأسئلة الشائعة.
- `gallery.html` — معرض الرسومات والبحث والتصنيفات ورفع الأعمال.
- `artists.html` — الفنانين وطلبات الصداقة والملفات الشخصية والمحادثات الخاصة.
- `communities.html` — المجتمعات وإنشاؤها وطلبات الانضمام والمحادثات الجماعية.
- `notifications.html` — الإشعارات ونتائج الطلبات وحذف الإشعارات المقروءة.
- `profile.html` — الحساب وتعديل الملف وتسجيل الخروج.

## الوظائف التجريبية

تعمل الواجهة محليًا على المتصفح باستخدام `localStorage`: الحساب التجريبي، البحث والتصفية، نشر الرسومات، الإعجابات والتعليقات، المتابعة، ملفات الفنانين، طلبات الصداقة، طلبات الانضمام، عدادات الرسائل غير المقروءة، المحادثات النصية والصور، الإشعارات، إنشاء المجتمعات وتعديل الملف الشخصي.

## حدود النسخة الحالية

هذه نسخة Frontend Demo وليست خدمة اجتماعية متعددة المستخدمين. المحادثات والإشعارات والطلبات محفوظة في متصفح المستخدم الحالي فقط ولا تصل إلى مستخدم آخر. تسجيل الدخول المحلي ليس بديلًا عن مصادقة آمنة، وتجزئة كلمة المرور في المتصفح ليست بديلًا عن تخزين كلمات المرور على الخادم. أزرار Google وFacebook توضح موضع التكامل فقط ولا تنفذ OAuth فعليًا. يلزم Backend وقاعدة بيانات وتخزين ملفات وخدمة لحظية مثل Socket.IO لتفعيل الحسابات الحقيقية والمراسلة بين المستخدمين والصلاحيات والإشعارات الفعلية.
