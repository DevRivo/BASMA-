# بصمة | BASMA — واجهة أمامية (HTML/CSS/Vanilla JS)
## التشغيل
افتح `index.html` مباشرة، أو شغّل خادمًا محليًا: `python3 -m http.server 8000` ثم افتح http://localhost:8000
حساب تجريبي: demo@basma.art / 123456 (أو أنشئ حسابًا جديدًا).
## الهيكل
index/gallery/artists/communities/notifications/profile.html — css/ (global + صفحة لكل صفحة) — js/ (data, global, auth + صفحة لكل صفحة) — assets/images
## مُحاكى محليًا (يتطلب خادمًا في الإنتاج)
تسجيل الدخول والجلسة (localStorage ليست أمانًا حقيقيًا)، Google/Facebook (أزرار تجريبية)، المحادثات (لا تواصل لحظي بين مستخدمين)، الإشعارات، الإعجابات والتعليقات، رفع الصور (تُحفظ مصغّرة في المتصفح)، الصداقات والمجتمعات، وحماية الصفحات.
## قائمة الاختبار
تسجيل/دخول/خروج • حماية الصفحات • FAQ (مفتوح واحد) • بحث وتصنيف الرسومات • لايك/تعليق • رفع رسمة • طلب صداقة • ملف فنان • محادثة (نص/صورة فقط) • إنشاء/انضمام مجتمع • محادثة جماعية • قبول/رفض الإشعارات • Esc وقفل التمرير • موبايل/تابلت/ديسكتوب
